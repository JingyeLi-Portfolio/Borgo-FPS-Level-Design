# Borgo FPS 关卡设计

## 项目简介

这是一个基于 Unity 制作的 FPS 关卡设计项目。

本项目以竞技 FPS 游戏体验为目标，通过空间布局、路线规划和战斗区域设计，探索玩家移动、战斗节奏与关卡体验之间的关系。

## 项目信息

- 项目类型：FPS 竞技地图白盒设计
- 开发引擎：Unity
- 项目职责：关卡设计、地图搭建、空间规划

## 设计目标

希望通过合理的空间结构，让玩家在探索过程中形成清晰的目标感，并在战斗区域中产生多样化的策略选择。

- 如何利用空间结构引导玩家行动
