# Borgo FPS 关卡设计

## 项目简介

Borgo 是一个基于 Unity 制作的 FPS 竞技地图白盒设计项目。

设计灵感来源于欧洲传统城区与现代城市开发的交界区域，通过传统建筑紧凑尺度与现代空间开放形态的对比，探索空间结构如何影响玩家移动、战斗节奏与决策体验。

项目类型：
- FPS 竞技地图
- CS 炸弹拆除模式（双包点）
- 5v5 对战关卡 Whitebox

# 设计理念

优秀的关卡不仅是场景搭建，而是通过空间、视线、路径关系塑造玩家体验。

本项目尝试将建筑空间设计方法应用于游戏关卡：

- 空间尺度控制玩家节奏
- 视线关系影响玩家决策
- 路线组织创造战术选择


# 关卡设计分析


## 1. 整体空间布局

Borgo 将地图划分为不同空间节奏：

- 紧凑空间：制造近距离冲突
- 开放空间：提供中远距离交战
- 空间节点：形成玩家决策点


## 2. 玩家动线设计

地图主要包含：

- T → A → CT
- 中路连接空间
- T → B → CT


通过多路径设计，提高玩家转点和进攻选择。


## 3. 战斗空间设计

战斗空间并不是简单增加掩体，而是通过：

- 视线控制
- 空间尺度
- 遮挡关系
- 路线选择

共同控制玩家暴露程度。


## 4. 设计迭代

初版设计中发现：

- T进攻路线过于顺畅
- 部分空间尺度过大
- 玩家决策不足


优化方式：

- 增加紧凑空间形成瓶颈
- 调整建筑尺度
- 利用开放区域创造风险与收益
